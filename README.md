本插件会在 AstrBot 管理面板打开或刷新时自动播放全屏启动动画。它同时支持代码动画和本地视频，可按设置自动衔接，播放完成后再显示 AstrBot 原生管理面板。

## 功能说明

### 自动启动

- 插件加载后自动接入 AstrBot Dashboard。
- 打开或刷新管理面板时自动播放，无需手动进入插件页面。
- 动画开始前隐藏面板，避免管理界面提前闪现。
- 动画结束后平滑淡入 AstrBot 面板。

### 三种启动流程

1. **仅播放视频**：关闭代码动画，直接播放单段或双段视频。
2. **代码动画后接视频**：先播放内置代码动画，再按设置播放单段或双段视频，最后进入 AstrBot。
3. **仅播放代码动画**：代码动画结束后直接进入 AstrBot，不加载启动视频。

### 代码动画

- 代码动画及其运行资源已打包进插件，无需额外安装原项目。
- 可在“AstrBot 原版代码动画”和“OpenAI GPT Codex 风格”之间切换。
- 也可选择“Gemini 彩虹星光风格”：身份编号 0003，Gemini 标志与欢迎语、淡彩虹背景及彩色四角星流。
- GPT Codex 风格基于最初代码动画的完整分幕流程，统一使用 ChatGPT / Codex 文案和 OpenAI Blossom 图标。身份资料为 ASTRBOT / 0002 / 权限等级 3；保留访问许可、身份确认、速度控制和声音开关。背景为暗色，间歇出现垂直下落的绿色代码，系统减少动态效果时关闭代码雨。
- Codex 版前五段语音保留最初代码动画的原始录音。欢迎语仅将 DeepSeek 品牌名替换为以原录音作参考、本地 IndexTTS 2.5 生成的 ChatGPT 片段，再匹配时长与响度；保留前后台词及约 3.74 秒的总时长。合成词的音色与发音需以实际试听为准，不能保证与原声完全一致。素材加载失败时不切换到系统合成音色。
- 声音开关控制原版语音和音效，欢迎录音在身份验证结束后播放。保留跳过、速度控制及原版键盘交互。
- 使用独立全屏页面运行，不会把样式或事件带入 AstrBot 管理面板。
- 支持暖白、暗色两种主题。
- 支持 `0.75×`、`1×`、`1.25×`、`1.5×`、`2×` 播放速度。
- 可以自动连续播放，也可以在指定阶段等待点击、Enter、空格确认。
- 可单独开启或关闭代码动画的语音与音效。
- 支持画面内跳过操作，结束后自动交回插件启动流程。

### 视频动画

- 新视频已加入素材池；在“单段视频文件”“前段视频文件”或“后段视频文件”填写上述完整文件名即可选用。升级后已有播放选择保持原样。
- 支持 `.mp4`、`.webm`、`.m4v`、`.mov` 文件。
- 支持只播放一段视频。
- 支持依次播放前段和后段两段视频。
- 可分别指定单段、前段、后段视频文件名。
- 支持片尾交叉溶解、完整播放后淡入、点击后进入三种方式。
- 支持视频声音、点击开启声音和点击直接进入。
- 可设置 1、1.5、2、3、4 秒淡入时长。
- 视频加载失败时会尝试下一段，或安全进入 AstrBot，不生成额外动态背景。

### 面板与视觉效果

- 启动画面底部进度条已删除。
- 进入管理面板后完整移除启动层、视频和代码动画页面。
- 不修改面板背景、卡片透明度、颜色、滤镜或布局。
- AstrBot 面板保持原生外观，不会整体发灰。
- 不添加进入面板后的极光、动态背景或视频背景。

### 素材管理与可靠性

- 设置中提供“打开视频文件夹”开关，保存后自动打开素材目录并复位。
- 自定义视频放在插件的 `assets/videos/` 目录中，重载插件后生效。
- 插件停用或卸载时会撤销 Dashboard 注入。
- 不修改 AstrBot Python 源码。
- Dashboard 更新或替换后，重载插件即可重新安装启动入口。
- 内置超时保护；动画异常时不会让管理面板永久隐藏。

## 安装

1. 打开 AstrBot 管理面板。
2. 进入「扩展 → 插件 → 安装插件」。
3. 上传 `astrbot_plugin_boot_animation-1.1.2.zip`。
4. 安装完成后重载一次插件。
5. 刷新 AstrBot 管理面板。

支持 AstrBot 4.16～4.x，不需要安装第三方 Python 依赖。

## 配置项目

| 设置 | 功能 |
| --- | --- |
| 开启启动动画 | 总开关；关闭后移除管理面板启动入口 |
| 播放影片声音 | 控制视频声音，仍受浏览器自动播放规则限制 |
| 点鼠标直接进入 | 点击启动画面后直接进入面板 |
| 显示底部提示文字 | 显示或隐藏启动操作提示 |
| 代码启动动画 | 关闭、代码动画后接视频、仅代码动画 |
| 代码动画样式 | AstrBot 原版、OpenAI GPT Codex 或 Gemini 彩虹星光风格 |
| 代码动画主题 | 暖白或暗色主题 |
| 代码动画速度 | 选择代码动画播放速度 |
| 代码动画要求确认 | 在动画阶段等待用户操作后继续 |
| 代码动画语音和音效 | 控制代码动画自身声音 |
| 淡入时长 | 控制启动层退出和面板显示的过渡时长 |
| 进入方式 | 片尾交叉溶解、放完再淡、点击才进 |
| 视频播放段数 | 单段或前后两段 |
| 单段视频文件 | 单段模式使用的视频 |
| 前段视频文件 | 双段模式首先播放的视频 |
| 后段视频文件 | 双段模式随后播放的视频 |
| 打开视频文件夹 | 保存配置后打开视频素材目录 |
| 素材池 | 选择可参与播放的视频文件 |

设置保存后，请重载插件并刷新管理面板。

## 自定义视频位置

标准安装后的目录通常是：

```text
AstrBot/data/plugins/astrbot_plugin_boot_animation/assets/videos/
```

将视频复制到该目录后重载插件。建议使用启用 faststart 的 H.264 + AAC MP4，以获得更好的浏览器兼容性和加载速度。

插件运行时会把所需资源复制到：

```text
AstrBot/data/dist/astrbot-boot-animation/
```

这个目录由插件自动维护，不建议直接修改。若插件无法找到 Dashboard，可以设置环境变量 `ASTRBOT_DASHBOARD_DIST`，使其指向实际的 Dashboard `dist` 目录。
